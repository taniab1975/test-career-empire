# Career Empire development test copy

Public development snapshot of the game source and assets from
`Emmanuel-ICT-Support/GTCEM-Career-Empire` commit
`b596b0e760dc0949afd120d74166cb19797abfa2`
(branch `release/all-projects-20261012`).

This repository is a temporary development destination. The ECC production
repository and deployment are separate. No website deployment is claimed by
this initial upload. Untransferred Mac fixes are not included.

The copy preserves the tracked game code, tests, tools and game assets, including
the reviewed Avatar Studio production reference and student art brief used by
the game. Private planning/history documents, blueprint source material,
receipts, CI workflows, credentials, dependencies and caches are excluded.

Run `npm run dev` to serve locally on port 8000 and `npm run check` for source
and release-asset verification. Install locked test dependencies with `npm ci`
before running `npm test` or Playwright. Browser acceptance is still pending.
